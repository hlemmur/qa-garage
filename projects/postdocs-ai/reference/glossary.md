# Glossary

Canonical product terms. Keep small — only terms that affect test design or client communication.

| ID | Term | Definition | Status | Source | Links |
|----|------|------------|--------|--------|-------|
| G-001 | Grant call | A specific funding opportunity from an agency (e.g. VR, Formas, Vinnova, Energimyndigheten) with its own template, requirements, and deadline. | inferred | docs:https://learn.postdocs.ai/features | F-005, UC-004 |
| G-002 | Proposal | A workspace tied to one grant call where the researcher uploads materials, generates/edits sections, reviews eligibility, and exports. | inferred | docs:https://learn.postdocs.ai/guides | PM-005–PM-012 |
| G-003 | Synopsis / outline | High-level project description written on the Setup page; guides how the AI answers grant questions and interprets uploaded files. | inferred | docs:https://learn.postdocs.ai/tips-and-tricks | F-008, UC-005 |
| G-004 | Background materials | Uploaded files (PDF, Word, PowerPoint) — previous proposals, papers, reports — used as AI context. User should describe how each file should be used. | inferred | docs:https://learn.postdocs.ai/tips-and-tricks | F-007, UC-005 |
| G-005 | Project description | Main proposal body sections generated and edited after Setup; basis for submission-form texts. | inferred | docs:https://learn.postdocs.ai/features | F-010–F-012 |
| G-006 | Submission-form texts | Short-form outputs derived from the project description: abstract, popular science summary, sex- and gender perspectives, and related funder form answers. | inferred | docs:https://learn.postdocs.ai/features | F-013, UC-008 |
| G-007 | Pre-loaded template | Grant-call-specific section structure and limits automatically loaded when a grant is selected — user does not add the template manually. | inferred | docs:https://learn.postdocs.ai/features | F-005, F-006, R-002 |
| G-008 | Bookmark group | Custom folder for organizing bookmarked grants (e.g. "Priority Applications", "2026 Deadlines"). | inferred | docs:https://learn.postdocs.ai/features | F-003, UC-003 |
| G-009 | Grant status | Lifecycle state of a call: Open, Forthcoming, or Closed. | inferred | docs:https://learn.postdocs.ai/features | F-002, R-003 |
| G-010 | Assessment | Product feature that evaluates the draft against funder assessment criteria and guiding questions. | inferred | docs:https://learn.postdocs.ai/features | F-015, UC-010 |
| G-011 | Collaborator permission | Access level for invited users: **view**, **comment**, or **edit** (per FAQ). | inferred | docs:https://learn.postdocs.ai/ (FAQ) | F-019, UC-011, Q-009 |
| G-012 | PI (persona) | Experienced principal investigator applying for national research grants in Sweden; primary documented user. | inferred | docs:https://learn.postdocs.ai/ | qa-project-context |
| G-013 | VR | Vetenskapsrådet (Swedish Research Council) — documented funding agency filter example. | inferred | docs:https://learn.postdocs.ai/features | F-002 |
