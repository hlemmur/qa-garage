# Template QA Project

Copy this directory to create a project-specific black-box QA Garage target. Each project is its own QA root with a single source of truth at `.agents/qa-project-context.md`.

## Layout

- `.agents/qa-project-context.md` - single source of truth (every skill reads it first).
- `risk-matrix.md` - product/delivery risk, scored (from `risk-based-testing`).
- `journeys/` - real user journey maps (from `journey-mapping`).
- `strategy.md`, `plan.md` - test strategy and current-phase plan.
- `test-data.md` - accounts/data matrix for concurrency, permissions, invitations.
- `decisions.md`, `questions.md`, `known-issues.md` - the human-decides loop.
- `open-items.md` - generated by `qa:review` (do not hand-edit).
- `tasks/qa-tasks.md` - work ledger.
- `scenarios/`, `tests/e2e/`, `evidence/`, `reports/` - execution artifacts.

## Setup

1. Copy `_template` to `projects/<project-name>`.
2. Fill `.agents/qa-project-context.md` with the `qa-project-context` skill (from docs + exploration; targets are black-box).
3. Build `journeys/` and `risk-matrix.md` with `journey-mapping` and `risk-based-testing`.
4. Produce `strategy.md` and `plan.md` with `test-strategy` and `test-planning`.
5. Fill `test-data.md`; keep real secrets in `config/target.env.example` outside git.
6. Track requested QA work in `tasks/qa-tasks.md`.
7. Add scenarios under `scenarios/` and Playwright tests under `tests/e2e/`.

## Commands

```bash
QA_PROJECT=_template npm run qa:knowledge   # validate .agents/qa-project-context.md
QA_PROJECT=_template npm run qa:review      # regenerate open-items.md (add -- --gate to fail on blockers)
QA_PROJECT=_template npm run qa:tasks
QA_PROJECT=_template npm run qa:smoke
QA_PROJECT=_template npm run qa:regression
QA_PROJECT=_template npm run qa:explore -- "template exploratory charter"
QA_PROJECT=_template npm run qa:report
```
