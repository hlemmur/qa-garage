# Exploratory Charters

Use these as starting points for AI-assisted exploration.

## Charter: First Impression

- Mission: understand the main product surfaces from the landing state.
- Persona: new or unauthenticated user.
- Risks: broken navigation, unclear empty states, blocked onboarding.
- Evidence: screenshots for surprising states, trace for broken flows.

## Charter: Save And Reload

- Mission: verify important user work survives refresh and navigation.
- Persona: authenticated user.
- Risks: data loss, stale UI, failed persistence, misleading success states.
- Evidence: trace, before/after screenshots, console errors.

## Charter: Error Recovery

- Mission: probe how the app responds to invalid input, slow loading, or failed requests.
- Persona: typical user.
- Risks: silent failures, confusing validation, unrecoverable states.
- Evidence: screenshots, console logs, network notes.
